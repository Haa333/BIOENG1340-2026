*Week07 · 6 code cells*

Continuation of MR image formation. Topics: the **spin-echo** pulse sequence (vs gradient echo), **image contrast** (T1/T2/PD weighting via TR/TE), **inversion recovery** (STIR/FLAIR), deeper **k-space theory** (field-of-view, resolution, cropping → blur, undersampling → aliasing, k-space filtering = convolution), and **BOLD / functional MRI**. Advanced sequences (phase-contrast 4D flow, diffusion-tensor imaging, MR spectroscopy, gadolinium contrast) are summarized at the end.
